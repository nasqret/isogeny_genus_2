# Reconstruction Guide

The reconstruction proceeds in four layers:

1. archive the exact source and external computation repository;
2. enumerate every computational claim in an atomic ledger;
3. implement independent SageMath and Magma certificates;
4. link each article claim to executable code and saved evidence.

The [original article copy](original_article.md) is generated from the archived
TeX source. The [claim index](../claims/index.md) is generated from the same
ledger that drives the dashboard.
